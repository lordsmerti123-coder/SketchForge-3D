# Русификация SketchForge

Форк [SketchForge-3D](https://github.com/Formsmith746/SketchForge-3D) с русским
интерфейсом. Работа ведётся в ветке `russification`.

## Зачем

SketchForge — редактор 3D-моделей, который работает в браузере и не требует
установки. Он задуман как замена Tinkercad для занятий с детьми: те же простые
действия — построить фигуру, вырезать отверстие, сгруппировать детали, —
но без регистрации и без отправки моделей на чужой сервер.

Для занятий с русскоязычными школьниками нужен интерфейс на русском.
В оригинале его нет.

## Что переведено

Перевод сделан через `next-intl`. Русский становится языком по умолчанию,
английский остаётся вторым — его можно выбрать.

| Часть интерфейса | Что переведено |
|---|---|
| Каталог фигур | названия и описания всех примитивов |
| Инспектор фигуры | свойства, размеры, подсказки |
| Настройки рабочей области | единицы измерения, сетка, тема |
| Панель фасок и скруглений | параметры обработки кромок |
| Оверлеи инструментов | перемещение, поворот, размеры |
| Туториалы | пошаговые подсказки для новичков |
| Задания | тексты учебных задач |
| Меню трея десктопа | пункты приложения |
| Ошибки API | сообщения на понятном языке |

Файлы переводов: `apps/web/src/i18n/messages/ru.json` и `en.json`.
Русский каталог крупнее английского — часть строк дополнена пояснениями,
которых в оригинале не было.

## Как устроен перевод

Локаль хранится в cookie `NEXT_LOCALE`, читается в
`apps/web/src/i18n/routing.ts`, сообщения загружаются в `request.ts`.
Провайдер `NextIntlClientProvider` обёрнут в `apps/web/src/app/layout.tsx`.

В компонентах используется `useTranslations()` — жёстко вписанных строк
в интерфейсе не остаётся.

## Занятия в классе

Проект задуман для работы с группой: редактор открывается у каждого ученика,
а языковая модель поднимается один раз на машине учителя, и ученики
обращаются к ней по локальной сети.

Как это настроить — в отдельном документе: [TEACHER-SETUP.md](TEACHER-SETUP.md).
Там же сказано, как открыть порт только для своей сети и что делать,
если ученик не подключается.

## Пакет задач

В `docs/russification/` лежит описание работы: разбивка перевода на задачи
по компонентам, правила оформления ключей и порядок сборки каталога.
Пакет сделан так, чтобы перевод можно было продолжать частями и отдавать
разным исполнителям.

```
docs/russification/
├── README.md      обзор и текущее состояние
├── RULES.md       правила перевода и оформления ключей
├── TASKS.md       список задач и зависимости между ними
├── tasks/         описания задач по компонентам
└── keys/          готовые наборы ключей для слияния в каталог
```

## Сборка

Требования и команды — в [README оригинального проекта](README.md).
Кратко:

```bash
npm install
npm run dev      # разработка
npm run build    # сборка
```
