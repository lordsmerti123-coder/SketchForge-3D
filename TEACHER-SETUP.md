# Занятия в классе: настройка на несколько машин

Как поставить SketchForge на компьютеры учеников так, чтобы редактор работал
у каждого, а языковая модель — одна на всех, на машине учителя.

---

## Зачем это нужно

SketchForge работает **полностью локально**: редактор крутится в браузере
ученика, модели не нужен интернет. Если вы пользуетесь только редактором,
ничего настраивать не надо — достаточно открыть `http://localhost:3000`.

Схема с учительским сервером нужна, когда вы хотите дать ученикам
**ИИ-помощника**, который управляет редактором. Модель весит десятки
гигабайт, и ставить её на каждый компьютер неразумно. Поэтому модель
поднимается один раз на машине учителя, а ученики обращаются к ней по
локальной сети.

```
   компьютер ученика                    компьютер учителя
┌──────────────────────┐            ┌──────────────────────┐
│  браузер             │            │  LM Studio / Ollama  │
│  http://localhost:3000│           │  порт 1234 / 11434   │
│         │            │            │         ▲            │
│         ▼            │  локальная │         │            │
│  ИИ-агент ───────────┼───────────►│  языковая модель     │
└──────────────────────┘   сеть     └──────────────────────┘
```

Редактор и вычисления модели остаются у ученика. По сети передаётся только
запрос к языковой модели.

---

## Что нужно

- **Учитель:** компьютер с моделью (LM Studio или Ollama) и локальной сетью.
- **Ученики:** компьютеры в той же сети, Node.js и этот репозиторий.
- **Сеть:** одна локальная сеть, без выхода в интернет.

---

## Шаг 1. Машина учителя: поднять модель в сеть

По умолчанию серверы слушают только свой компьютер. Нужно разрешить приём
запросов из сети.

**LM Studio:** вкладка Developer → запустить сервер → включить прослушивание
сети (`0.0.0.0`), порт оставить `1234`.

**Ollama:** задать переменную окружения перед запуском:

```powershell
$env:OLLAMA_HOST = "0.0.0.0:11434"
ollama serve
```

**Проверка с машины учителя:**

```powershell
curl http://localhost:1234/v1/models
```

Список моделей должен вернуться.

---

## Шаг 2. Файрвол — открыть порт только для своей сети

> **Это важный шаг, не пропускайте его.**

Порт нужно открыть на машине учителя, иначе ученики не подключатся.

⚠️ **Открывайте порт только для доверенной локальной сети.** У серверов,
совместимых с OpenAI API, нет надёжной проверки подлинности: любой, кто
знает адрес и порт, сможет пользоваться вашей моделью. Не выставляйте
порт наружу через интернет.

**Windows, PowerShell от администратора:**

```powershell
New-NetFirewallRule -DisplayName "LM Studio локальная сеть" `
  -Direction Inbound -Protocol TCP -LocalPort 1234 `
  -RemoteAddress LocalSubnet -Action Allow
```

Ключевой параметр здесь — `-RemoteAddress LocalSubnet`: правило действует
только для компьютеров вашей локальной сети.

Для Ollama замените порт на `11434`.

**Как убрать правило после занятия:**

```powershell
Remove-NetFirewallRule -DisplayName "LM Studio локальная сеть"
```

### Узнать адрес машины учителя

```powershell
ipconfig | Select-String "IPv4"
```

Адрес будет вида `192.168.0.37`. Он нужен на следующем шаге.

---

## Шаг 3. Машины учеников: указать адрес учителя

На каждом компьютере ученика откройте файл `opencode.json` в папке проекта
и замените адрес модели. Было:

```json
"baseURL": "http://127.0.0.1:1234/v1"
```

Стало — с адресом машины учителя:

```json
"baseURL": "http://192.168.0.37:1234/v1"
```

Идентификаторы моделей оставьте те же, что у учителя.

Если на сервере учителя включён ключ доступа, добавьте рядом поле `apiKey`.

---

## Шаг 4. Проверка

**С машины ученика** убедитесь, что сервер виден:

```powershell
curl http://192.168.0.37:1234/v1/models
```

Если список моделей вернулся — связь есть.

**Затем запустите редактор** на машине ученика:

```powershell
npm run dev
```

Откройте `http://localhost:3000`, попросите помощника что-нибудь построить.
Если модель ответила — всё настроено.

---

## Если что-то не работает

**Ученик не подключается.** Проверьте в порядке:

1. `curl http://<адрес-учителя>:1234/v1/models` с машины ученика.
2. Файрвол на машине учителя — правило создано и активно.
3. Обе машины в одной сети (сравните первые три числа адресов).
4. Сервер на машине учителя запущен и слушает `0.0.0.0`, а не `127.0.0.1`.

**Модель отвечает медленно.** Первый запрос всегда дольше: модель
загружается в память. Дальше быстрее. Если учеников много и они работают
одновременно, запросы встают в очередь — модель обрабатывает их по одному.

**Ошибка про MCP или «редактор не найден».** Вкладка с редактором должна
быть **открыта в браузере**: только тогда она сообщает о себе агенту.
Если вкладок нет, помощник не знает, куда отправлять команды.

---

## Сколько учеников выдержит одна модель

Одна модель обрабатывает запросы **по очереди**. На занятии это заметно,
если весь класс одновременно просит помощника что-то построить.

Практический совет: давайте задания так, чтобы часть работы ученики делали
руками — редактор работает у каждого независимо и мгновенно. Модель нужна
для подсказок и сложных построений, а не для каждой операции.

---

## Что остаётся у ученика, а что уходит по сети

| Что | Где считается |
|---|---|
| Редактор, поворот модели, нарезка | **у ученика**, в браузере |
| Построение фигур, логические операции | **у ученика** |
| Запросы к ИИ-помощнику | **у учителя**, на модели |

Сеть нужна только для «мозгов» помощника. Если она пропала, редактор
продолжает работать — перестаёт отвечать только ИИ.
