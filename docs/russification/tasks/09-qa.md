# Задача 09 — QA и финальная сборка

## Цель
Проверить полную русификацию и при необходимости пересобрать портативное приложение.

## Зависимость
Запускать после задач 01–08.

## Шаги

### 1. Статическая проверка
- `node "node_modules\typescript\bin\tsc" -p "apps/web/tsconfig.json" --noEmit` — 0 ошибок.
- Валидность `en.json`/`ru.json` (ConvertFrom-Json).
- Поиск остатков английского текста в ключевых компонентах (grep по
  `SketchForgeEditor.tsx`, `WorkplaneViewport.tsx`, `SketchWorkspace.tsx` на
  `>Create<`, `>Cancel<`, `title="`, `aria-label="` и т.п.) — убедиться, что остались только
  осознанно не-переводимые (идентификаторы/имена).

### 2. Запуск и визуальная проверка
- `node_modules\.bin\next.cmd dev apps/web` (или `npm run dev`).
- Пройти по экранам: дашборд → создать/открыть проект → редактор (меню, тулбар, сцена,
  виды камеры) → панель фаски/скругления → туториалы → задания → настройки.
- Убедиться: русский по умолчанию; интерфейс на русском; нет сырых `namespace.key`.

### 3. Совместимость проектов
- Открыть существующий `.skf` и сохранить — структура не изменилась (внутренние значения
  фигур/шрифтов/единиц остались английскими; переведено только отображение).

### 4. Пересборка портативного приложения (если нужно)
Портативная сборка находится в `release/SketchForge-1.0.9-win-x64`. Чтобы учесть правки:
- web-бандл: `node apps/desktop/build-web.mjs`
- упаковка: `node node_modules\electron-builder\out\cli\cli.js --dir --win --x64 --publish never --config <temp>\electron-builder-portable.yml`
  (или использовать существующий процесс; важно — с `npmRebuild: false`, см. README сборки).
