# Задача 02 — Русификация каркаса редактора (SketchForgeEditor)

## Цель
Перевести весь видимый текст в `apps/web/src/components/SketchForgeEditor.tsx`
(около 10 400 строк, самый большой файл): меню, тулбар, окна импорта/экспорта,
уведомления, подписи, aria/заголовки.

## Файлы
- Только `apps/web/src/components/SketchForgeEditor.tsx`.
- Новые ключи — в `docs/russification/keys/02-keys.json`.
- НЕ редактировать `en.json`/`ru.json` (это задача 08).

## Namespace
- Переиспользовать существующие ключи `editor.*`, `shapes.*`, `dashboard.*` из `en.json`,
  где смысл совпадает (проверь `apps/web/src/i18n/messages/en.json`).
- Новые ключи добавлять в `editor` (меню/инструменты/уведомления/окна) и, если строка
  относится к «окну/хрому» приложения (заголовки окон, кнопки Cancel/Save), — в новый
  namespace `appShell`. Не плодить лишних неймспейсов.

## Что искать и переводить
В файле текст встречается в нескольких формах:
1. JSX-текст: `>Create<`, `>Dashboard<`, `>Cancel<`, `>Finish<`, `>File name<` и т.п.
2. Атрибуты: `aria-label="..."`, `title="..."`, `placeholder="..."`.
3. Массивы/конфиги меню и тулбара: `{ label: "Line", ... }`, списки инструментов
   (`Basic Shapes`, `Clipboard`, `Arrange`, `Combine`, `Draw`, `Edit`…), пункты
   контекстного меню.
4. Уведомления/статусы: строки вида `"Could not ..."`, `"Opened ..."`, `"Exported ..."`,
   drag-and-drop подсказка `"Drop STL, OBJ, STEP, or SVG files"`.

## Правила (обязательно; подробности в RULES.md)
- НЕ переводить: имена фигур как данные (`kind`/`name` в `toolbarShapeAssets` и подобные
  идентификаторы), имена шрифтов, типы шестерён, значения enum/units/пресетов.
  Для названий фигур в меню используй `shapeKindLabelKey(kind)` + `t(...)` (см. RULES §1).
- НЕ переводить строки, участвующие в сравнениях/условиях (ищи `===`, `includes`,
  `startsWith`, `switch` по строковым литералам).
- Плейсхолдеры: `t("editor.opened", { name })` — значения передавать аргументами.
- Файл большой: иди по частям (сверху вниз), после каждого логического блока не забывай
  контекст. Не меняй структуру и не рефакторь.

## Вывод новых ключей
В `docs/russification/keys/02-keys.json` писать ТОЛЬКО новые ключи:
```json
{
  "editor": { "saveFile": { "en": "Save file", "ru": "Сохранить файл" } },
  "appShell": { "close": { "en": "Close", "ru": "Закрыть" } }
}
```

## Проверка
- `node "node_modules\typescript\bin\tsc" -p "apps/web/tsconfig.json" --noEmit` — без ошибок.
- Убедись, что `useTranslations` импортирован в файл (это client-компонент).

## Отчёт
Файлы, число заменённых строк, число новых ключей, список осознанно пропущенных мест и почему.
