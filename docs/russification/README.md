# Русификация SketchForge — пакет задач для агентов

Этот пакет разбивает **полную русификацию** интерфейса SketchForge на независимые,
проверяемые задачи, которые можно отдавать агентам по одной или параллельно.

## Текущее состояние (важно понимать перед стартом)

Приложение уже частично русифицировано через `next-intl` v4:

- Провайдер `NextIntlClientProvider` обёрнут в `apps/web/src/app/layout.tsx` — все клиентские
  компоненты уже могут вызывать `useTranslations()`. Менять layout не нужно.
- Локаль хранится в cookie `NEXT_LOCALE` (`apps/web/src/middleware.ts`), читается в
  `apps/web/src/i18n/routing.ts`; сообщения грузятся из
  `apps/web/src/i18n/messages/{en,ru}.json` (`apps/web/src/i18n/request.ts`).
- Уже переведены и используют `useTranslations`: дашборд (`src/app/page.tsx`),
  инспектор фигуры (`components/workplane/ShapeInspector.tsx`),
  настройки рабочей области (`components/workplane/WorkspaceSettingsModal.tsx`).

**Не переведено** (главная работа): весь редактор — `SketchForgeEditor.tsx` (10,4 тыс. строк),
`WorkplaneViewport.tsx` (8 тыс. строк), `SketchWorkspace.tsx`, панель фаски/скругления,
overlay-компоненты, туториалы, дашборд заданий, метки данных, ошибки API, меню трея десктопа.

В каталогах переводов **уже есть** неймспейсы `editor` (80 ключей), `shapes` (72),
`edgeModifier` (30), `tutorial`, `challenges`, `transforms`, `alignHandles`, `units` и др. —
их нужно **переиспользовать**, а не дублировать.

## Порядок и зависимости

```
01 (инфраструктура) ──► может идти параллельно с 02–07
02, 03, 04, 05, 06, 07 ──► независимы друг от друга (разные файлы)
08 (сборка каталога) ──► ждёт 02–06 (читает их keys/*.json)
09 (QA) ──► ждёт 01–08
```

- **Задачи 02–07 трогают разные файлы** и потому безопасны для параллельного запуска
  (например, через Agent Manager с worktree).
- **Единственный владелец `en.json`/`ru.json` — задача 08.** Задачи 02–06 НЕ правят JSON
  напрямую, а пишут список новых ключей в `keys/<id>.json`. Это исключает конфликты при
  параллельной работе над общими файлами переводов.
- Задача 07 (трей десктопа) работает с `apps/desktop/main.cjs` и НЕ использует JSON-каталог
  (Electron main-процесс вне React) — переводы хранятся локально в main.cjs.

## Как запускать агента по задаче

Каждому агенту давать такую инструкцию:

> Ты выполняешь задачу русификации SketchForge. Прочитай `docs/russification/RULES.md`
> (обязательно), затем `docs/russification/tasks/<id>.md`, и выполни его полностью.
> Файлы новых переводов пиши строго по формату из RULES.md в `docs/russification/keys/<id>.json`.
> В конце запусти проверку типов (команда в RULES.md) и убедись, что ошибок нет.

## Критерий готовности всей работы

- `npm run typecheck` (или эквивалент через node) проходит без ошибок.
- Dev-сервер компилируется без ошибок, интерфейс редактора/сцены/туториалов — на русском.
- Проекты `.skf` открываются и сохраняются без изменений структуры (внутренние значения
  не переведены, переведено только отображение).
- В `en.json`/`ru.json` нет дублирующихся ключей, JSON валиден.
